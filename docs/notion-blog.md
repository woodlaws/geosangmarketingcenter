# 노션 CMS 블로그 운영 가이드

## 1. 구조

- 목록: `https://geosangmarketing.com/blog`
- 상세: `https://geosangmarketing.com/blog/{slug}`
- 블로그 RSS: `https://geosangmarketing.com/blog/rss.xml`
- 서버 함수: `api/blog.js`
- 화면 스타일: `blog.css`
- 목록 필터·검색: `blog-client.js`

현재 사이트는 Next.js가 아닌 정적 HTML + Vercel Functions 구조입니다. 기존 페이지를 유지하면서 서버 함수가 노션 API를 호출해 HTML과 RSS를 생성합니다. 서버 함수는 최신 Notion API의 데이터 소스 구조를 사용하며, 환경변수로 받은 데이터베이스 ID에서 첫 데이터 소스를 찾아 공개 글을 조회합니다. API 응답과 HTML은 5분 캐시하며, Vercel CDN에는 5분 캐시와 10분 stale-while-revalidate를 적용합니다.

## 2. 노션 준비

1. 노션에서 전체 페이지 데이터베이스를 만들고 이름을 `거상마케팅센터 블로그`로 설정합니다.
2. Notion Integrations에서 내부 통합을 생성하고 읽기 권한 토큰을 발급합니다.
3. 데이터베이스 우측 상단 `연결` 메뉴에서 만든 통합을 연결합니다.
4. 데이터베이스 URL에서 데이터베이스 ID를 확인합니다.

토큰은 데이터베이스를 연결한 워크스페이스에서만 읽기 권한을 갖도록 최소 권한으로 운영하세요.

## 3. 데이터베이스 속성

| 속성명 | 권장 타입 | 용도 |
|---|---|---|
| 제목 | 제목(Title) | 글 제목 |
| Slug | 텍스트 | 영문 소문자 URL 키. 예: `naver-place-basics` |
| 카테고리 | 선택 | 목록 필터와 배지 |
| 핵심 질문 | 텍스트 | 상세 상단의 질문·답변 요약 박스 |
| 요약 | 텍스트 | 카드와 메타 설명 기본값 |
| 대표 이미지 | 파일과 미디어 | 카드·상세·OG 이미지 |
| 작성일 | 날짜 | 정렬, 표시, RSS 날짜 |
| 공개 여부 | 체크박스 | 체크한 글만 외부 공개 |
| 추천 여부 | 체크박스 | 목록 추천 영역 노출 |
| SEO 제목 | 텍스트 | 상세 `<title>`; 비우면 제목 사용 |
| SEO 설명 | 텍스트 | meta description; 비우면 요약 사용 |
| 키워드 | 다중 선택 | meta keywords와 카드 태그 |
| 관련 서비스 | 다중 선택 | 상세 서비스 링크 |
| CTA 문구 | 텍스트 | 상세 하단 버튼 문구 |
| CTA 링크 | URL | 사이트 내부 또는 공식 도메인 링크 |

권장 카테고리는 `스마트플레이스`, `AEO·GEO`, `AI 검색 최적화`, `블로그 마케팅`, `체험단 마케팅`, `식당 마케팅`, `병원·치과 마케팅`, `소상공인 마케팅`, `마케팅 사례`입니다.

관련 서비스 값은 다음 이름을 사용하면 자동으로 연결됩니다.

- 스마트플레이스 최적화 → `/services/smartplace`
- 블로그 마케팅, 체험단 마케팅 → `/services/content-sns`
- 식당 마케팅, 치과 마케팅 → `/marketing-types/local-store`
- 홈페이지 진단 → `/services/website-diagnosis`
- AEO·GEO 컨설팅 → `/services/aeo-geo`

## 4. Vercel 환경변수

Vercel 프로젝트의 Settings → Environment Variables에서 Production, Preview 환경에 아래 값을 등록합니다.

```text
NOTION_TOKEN=secret_발급받은_통합_토큰
NOTION_BLOG_DATABASE_ID=데이터베이스_ID
```

등록 후 새 배포가 필요합니다. 두 값은 `NEXT_PUBLIC_` 접두사를 사용하지 않으며 서버에서만 읽습니다. 저장소에는 실제 값을 커밋하지 않습니다.

## 5. 글 작성과 발행

1. 새 데이터베이스 행을 만들고 제목·Slug·카테고리·요약·작성일을 입력합니다.
2. 페이지 본문에 문단, 제목 2/3, 글머리표, 번호 목록, 인용문, 이미지를 작성합니다.
3. CTA와 관련 서비스를 확인합니다.
4. 미리 공개하지 않을 글은 `공개 여부`를 끈 채 작성합니다.
5. 검수 후 `공개 여부`를 체크하면 최대 캐시 시간 뒤 목록·상세·RSS에 반영됩니다.

지원 블록은 문단, H2, H3, 글머리표, 번호 목록, 인용문, 이미지입니다. 노션 이미지 URL은 만료될 수 있으므로 장기 보관이 중요한 대표 이미지는 노션에 직접 업로드하고 정기적으로 노출을 확인하세요.

## 6. SEO 및 검색 등록

상세 페이지는 canonical, Open Graph, BlogPosting, BreadcrumbList를 출력합니다. `/blog`는 CollectionPage와 공개 글 ItemList를 출력합니다. `sitemap.xml`에는 블로그 목록 주소가 포함되어 있습니다.

노션 글별 URL은 데이터베이스가 연결된 이후에 생성되므로 정적 `sitemap.xml`에는 자동 추가되지 않습니다. 발행 글이 쌓이면 동적 사이트맵 엔드포인트를 별도로 추가하는 것이 다음 단계입니다. 공개 글은 현재 `/blog/rss.xml`에서 자동 확인할 수 있습니다.

## 7. 오류 대응

- 환경변수가 없거나 노션 API가 일시 실패하면 목록은 빈 상태 안내와 상담 CTA를 표시합니다.
- 존재하지 않거나 비공개인 Slug는 404를 반환합니다.
- 토큰 오류가 발생하면 Vercel 로그에서 Notion API 상태 코드를 확인합니다.
- 공개 여부와 Slug 중복을 발행 전에 확인합니다.
