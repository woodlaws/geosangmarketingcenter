# Google Apps Script 배포 방법

대상 스프레드시트는 `거상마케팅센터_통합문의_DB`, 탭은 `문의DB`로 설정되어 있습니다.

1. Google Sheet에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 `Code.gs` 내용을 이 폴더의 `Code.gs` 전체 내용으로 교체하고 저장합니다.
3. **배포 → 새 배포 → 유형 선택 → 웹 앱**을 선택합니다.
4. 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 선택한 뒤 배포합니다.
5. Google 권한 요청을 승인하고 발급된 `/exec` 웹 앱 URL을 복사합니다.
6. 사이트 루트의 `contact-form-config.js`에 발급된 `/exec` URL을 설정합니다.
7. 사이트를 다시 배포한 뒤 `/contact`에서 1건을 테스트하고 `문의DB`의 새 행을 확인합니다.

Apps Script 코드를 수정한 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 변경사항이 반영됩니다.

현재 Web App POST 테스트에서 `sheet is not defined`가 반환된다면 배포된 코드가 시트 변수를 선언하지 않은 버전입니다. 이 폴더의 `Code.gs` 전체 내용으로 교체한 뒤 반드시 **새 버전**으로 다시 배포하세요.

## 저장 열 순서

`접수일시, 문의유형, 유입소스, 이름, 회사명, 연락처, 이메일, 참고링크, 업종유형, 관심서비스, 현재고민, 예산범위, 희망상담방식, 문의내용, 개인정보동의, 처리상태, 메모, UserAgent, PageURL`

## 보안 처리

- Apps Script URL 외에 비밀번호나 Google 계정 자격 증명을 사이트 코드에 넣지 않습니다.
- 허니팟 필드가 채워진 자동 입력은 시트에 기록하지 않습니다.
- 수식으로 해석될 수 있는 사용자 입력은 문자열로 저장합니다.
- 동시에 접수된 문의가 같은 행에 충돌하지 않도록 Script Lock을 사용합니다.
